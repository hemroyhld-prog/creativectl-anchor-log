# Governance Model

This project is currently maintained by a single primary maintainer.

---

## Maintainer

- Responsible for reviewing and merging contributions.
- Responsible for security decisions.
- Responsible for release signing and versioning.

---

## Decision Making

- Technical decisions prioritize security, clarity, and maintainability.
- Breaking changes require a documented version increment.
- Security fixes may be expedited.

---

## Contributions

Contributions are welcome and must follow guidelines defined in `CONTRIBUTING.md`.

All commits must be cryptographically signed.

---

This governance model may evolve as the project grows.
