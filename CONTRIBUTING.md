# Contributing Guidelines

Thank you for contributing to CreativeCTL Anchor Protocol.

## Principles

- All changes must preserve deterministic verification.
- Merkle construction rules must remain reproducible.
- Public anchoring guarantees must not be weakened.

## Development Process

1. Fork repository
2. Create feature branch
3. Add tests (if applicable)
4. Submit pull request

## Protocol Changes

Any breaking change requires:

- Version increment (major)
- SPECIFICATION.md update
- CHANGELOG.md entry
- New tagged release
